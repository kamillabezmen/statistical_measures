# Statistical Measures

Веб-сервис для работы со статистическими мерами.

Backend реализован на Go с использованием Gin и GORM.
Для хранения данных используется PostgreSQL.
Изображения и видео хранятся в MinIO.

Все методы веб-сервиса имеют префикс `/api`.

## Текущий пользователь

В лабораторной работе №3 авторизация ещё не реализована.

Текущий пользователь задаётся через singleton:

`currentUserID = 1`

Получение текущего пользователя выполняется функцией:

`singleton.GetCurrentUserID()`.

# API

## 1. Получение списка статистических мер

**GET /api/statistical-measures**

Возвращает только статистические меры со статусом `published`.

Удалённые записи в результат не попадают.

Поддерживается фильтрация по времени расчёта:

`GET /api/statistical-measures?calculation_time=2`

Для каждой записи дополнительно возвращаются:

- `is_creator` - является ли текущий пользователь создателем записи;
- `is_liked` - поставил ли текущий пользователь лайк;
- `likes_count` - количество лайков.

---

## 2. Получение черновика

**GET /api/statistical-measures/draft**

Возвращает черновик текущего пользователя.

ID черновика передавать не требуется.

У одного пользователя может существовать не более одного черновика.

---

## 3. Получение ленты

**GET /api/statistical-measures/feed**

Возвращает опубликованную запись из ленты.

Для получения следующей записи можно передать ID и параметр `next=true`:

`GET /api/statistical-measures/feed?id=1&next=true`

В ленту попадают только записи со статусом `published`.

---

## 4. Добавление статистической меры

**POST /api/statistical-measures**

Запрос передаётся в формате `multipart/form-data`.

Поля:

- `title` - название;
- `image` - файл изображения;
- `video` - файл короткого видео.

Изображение и видео загружаются в MinIO.

Для файлов автоматически формируются имена латинскими символами.
В базе данных сохраняются имена файлов.

Новая запись автоматически получает:

- текущего пользователя в качестве создателя;
- статус `draft`;
- дату создания.

При создании поля `description`, `formula`, `calculation_time` и `formed_at` могут иметь значение NULL.

---

## 5. Публикация черновика

**PUT /api/statistical-measures/:id/publish**

Переводит собственный черновик текущего пользователя из статуса:

`draft -> published`

Вернуть опубликованную запись обратно в `draft` нельзя.

Необязательные поля:

- `description`;
- `formula`;
- `calculation_time`.

Дата публикации `formed_at` формируется сервером.

---

## 6. Удаление статистической меры

**DELETE /api/statistical-measures/:id**

Выполняет логическое удаление собственной опубликованной записи.

Запись физически не удаляется из PostgreSQL.

Статус изменяется:

`published -> deleted`

Удалённые записи не возвращаются методами списка и ленты.

---

## 7. Лайк

**POST /api/statistical-measures/:id/like**

Тело запроса:

`{"value": 1}` - поставить лайк.

`{"value": 0}` - убрать лайк.

Операция выполняется от имени текущего пользователя.

---

## 8. Регистрация пользователя

**POST /api/users/register**

Создаёт нового пользователя.

Поля:

- `name`;
- `email`;
- `password`.

Email пользователя должен быть уникальным.

---

## 9. Аутентификация

**POST /api/users/auth**

Заглушка.

Аутентификация будет реализована в лабораторной работе №4.

---

## 10. Выход из системы

**POST /api/users/logout**

Заглушка.

Деавторизация будет реализована в лабораторной работе №4.

# Таблицы базы данных

## statistical_measures

Хранит статистические меры.

Поля:

- `id` - идентификатор;
- `title` - название;
- `description` - описание, может быть NULL;
- `formula` - формула, может быть NULL;
- `calculation_time` - время расчёта, может быть NULL;
- `status` - статус (`draft`, `published`, `deleted`);
- `image_url` - имя файла изображения;
- `video_url` - имя файла видео;
- `creator_id` - идентификатор создателя;
- `created_at` - дата создания;
- `formed_at` - дата публикации, может быть NULL.

## users

Хранит пользователей.

Поля:

- `id` - идентификатор;
- `name` - имя пользователя;
- `email` - уникальный email;
- `password` - пароль.

## user_statistical_measures_likes

Таблица связи пользователей и статистических мер.

Реализует связь многие-ко-многим для лайков.

Поля:

- `id` - идентификатор;
- `user_id` - идентификатор пользователя;
- `statistical_measure_id` - идентификатор статистической меры.

---

# Хранение файлов

Изображения и короткие видео хранятся в MinIO.

Bucket:

`statistical-measures`

При загрузке сервер генерирует новое имя файла латинскими символами.
В PostgreSQL сохраняется имя файла, а сам файл хранится в MinIO.
